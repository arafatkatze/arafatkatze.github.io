# If we could just

> An interactive boil-text experience. It opens with the "you didn't know that" confessions, then asks if we could just — pick a path (be lovers, be friends, stop talking) and watch it unravel phrase by phrase behind accreting frames, ending in a screen that keeps splitting into "love you".
